# Read To Me 📚🔊

Turn any book you own into audio — listen on the go, or read along with the kids.

**Open it:** https://jimmywilson1979-arch.github.io/read-to-me/

- **Scan paper books** page after page with the camera (free on-phone text reader, or Gemini for best accuracy)
- **Open ebooks** (DRM-free EPUB), **PDFs** (including scanned PDFs) and **text files**, or paste text
- **Listen** with free phone voices or ElevenLabs voices (including your own cloned voice)
- **Read along** — every word lights up as it's spoken; Kids mode has big text and tap-a-word-to-hear-it
- Sleep timer, speed control, remembers your place, MP3 download (ElevenLabs)

Everything is stored on the device. API keys are kept in the browser's local storage only.
